Strict British English spelling, wording, and structure for all project output — explanations, comments, markdown, the lot.

**Why:** Preference for consistency and clarity across the project. The tone should feel like a first-year uni course, complemented by the kind of informal ELI5 breakdowns found on the programming subreddit — not literal five-year-old speak, but approachable and human.

**How to apply:** Every explanation, comment, and markdown file uses British English (e.g. "colour", "initialise", "behaviour", "standardise", "regularisation"). Tone sits between textbook and casual — teach clearly, keep it friendly, never stiff. No first/second/third person pronouns (I, You, We, etc.) anywhere — comments, markdown, all of it. Analogies must always be paired with a contextual or real-life example — the analogy paints the picture, the concrete example grounds it.
